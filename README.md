## 🌟 Overview / درباره پروژه

**Windows Optimization Suite** is an open-source performance kit engineered specifically for competitive gamers, power users, and developers. It fine-tunes system responsiveness by flushing memory standby lists, configuring optimal TCP/IP parameters, activating ultimate performance power plans, and cleaning gigabytes of accumulated temporary junk.

پروژه **Windows Optimization Suite** مجموعه‌ای از اسکریپت‌های بهینه‌سازی پیشرفته برای ویندوز ۱۰ و ۱۱ است که به طور اختصاصی برای گیمرها و کاربران حرفه‌ای جهت کاهش لگ، افزایش FPS، پاکسازی حافظه Standby رم و حذف سرویس‌های سنگین پس‌زمینه طراحی شده است.

## 🚀 Quick Start / نحوه اجرا

### 1. Requirements
- Windows 10 (1903+) or Windows 11 (all versions).
- Administrator Privileges.

### 2. Launching
1. Download or clone this repository:
   `cmd
   git clone https://github.com/III85III/optimize_windows.git
   `
2. Right-click on **un.bat** and select **Run as Administrator**.
3. Choose your desired optimization module from the interactive menu.

etsh, powercfg, dism, eg, powershell).
